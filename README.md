# Medium Clone

A front-end clone of Medium's blogging interface, built with React. This project focuses on recreating Medium's clean reading layout and component structure as a learning exercise in React fundamentals.

## Features

- Medium-inspired article and feed layout
- - Reusable React components
  - - Responsive, content-focused design
   
    - ## Tech Stack
   
    - - React (bootstrapped with Create React App)
      - - JavaScript (ES6+)
        - - CSS
         
          - ## Getting Started
         
          - Clone the repository and install dependencies:
         
          - ```bash
            git clone https://github.com/Hritesh51/medium-clone.git
            cd medium-clone
            yarn install
            ```

            Run the app in development mode:

            ```bash
            yarn start
            ```

            Then open http://localhost:3000 in your browser.

            ## Build

            ```bash
            yarn build
            ```

            Builds the app for production to the `build` folder.

            ## Status

            This is a learning project and a work in progress. Contributions and suggestions are welcome.
